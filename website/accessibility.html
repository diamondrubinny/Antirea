Accessibility Statement

Last updated: 2026-11-09

We want everyone, including people with disabilities, to be able to use norea.rubinny.net. This statement covers this website only.

The standard we aim for

This website aims to conform to WCAG 2.1 level AA and to Israeli Standard IS 5568, which is based on the WCAG guidelines.

What we have done

  • Semantic HTML with ordered headings and landmarks (header, navigation, main content, footer).
  • A “Skip to main content” link, and full keyboard operation with a clearly visible focus indicator.
  • Right-to-left layout and correct language settings for Hebrew and Arabic — six languages in total.
  • Text alternatives for informative images.
  • Links in running text are underlined, not identified by colour alone; text colours meet AA contrast.
  • Responsive layout: no horizontal scrolling on phones, and usable at 200% zoom.
  • The cookie banner works with a keyboard and with screen readers, and “Reject” is as prominent as “Accept”.
  • Animations and smooth scrolling are switched off when your system asks for reduced motion.
  • An accessibility toolbar (see below).

Accessibility toolbar

The ♿ button in the bottom corner of every page opens options for larger text, high contrast, underlined links, a readable font and stopping animations. Your settings are saved only in your browser. The toolbar is a convenience — the site is built to be accessible without it.

How we tested

Self-assessment carried out on 9 November 2026: automated checks with axe-core (WCAG 2.0 and 2.1, levels A and AA) on every page in English, Hebrew and Arabic, with no violations found; keyboard-only testing; and layout checks on a 390-pixel-wide screen and at 200% zoom, left-to-right and right-to-left. This site has not yet been audited by an independent accessibility expert.

Known limitations

  • Languages other than English are machine-translated and may contain awkward wording.
  • The control-panel screenshot is illustrative; the text around it describes what it shows.
  • Testing with screen readers (NVDA, JAWS, VoiceOver) has not been completed yet.
  • The source code and documentation on GitHub are outside this website and follow GitHub’s own accessibility.

Report a problem

If anything on this site is hard or impossible to use, please tell us: open an issue on GitHub with the page address, what you were trying to do, and the browser or assistive technology you use. GitHub issues are public — please do not include personal information. Accessibility contact: Diamond Rubinny. We aim to respond within 14 days.
